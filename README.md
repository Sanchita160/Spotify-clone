# Spotify-clone (HTML & CSS)

A responsive **Spotify Web Player Clone** built using **HTML5** and **CSS3**.  
This project recreates the UI of Spotify’s web player, focusing on layout, styling, and responsiveness.

---

##  Features

- 🎧 Sidebar navigation (Home, Search, Library)
- 📚 Playlist & Podcast section
- 📊 Recently Played, Trending & Featured Charts
- 🎶 Sticky music player at the bottom
- 🎚️ Playback & volume sliders
- 💻 Fully responsive UI
- 🎨 Clean Spotify-like dark theme

---

##  Technologies Used

- **HTML5**
- **CSS3**
- **Font Awesome Icons**
- **Google Fonts (Montserrat)**
